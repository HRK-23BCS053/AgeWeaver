
# AgeWeaver

**Identity-Preserving Facial Age Progression Using Diffusion Models**

## Project Overview

AgeWeaver is a research-oriented project exploring facial age progression while preserving a person's identity.

The project will investigate diffusion-based generation, age-conditioned prompting, identity preservation, and evaluation against an appropriate baseline.

## Research Objectives

- Generate age-progressed facial images.
- Preserve identity across different target ages.
- Investigate prompt refinement and attention-control strategies.
- Evaluate results using documented, reproducible metrics.
- Compare the implementation fairly against the selected base paper.

## Research Foundation

The initial research foundation is the Face Time Traveller (FaceTT) paper.

The final implementation, dataset, metrics, and experimental protocol will be defined after reviewing the paper and available computing resources.

## Project Status

**Stage:** Initial setup and research planning

Implementation and experimental results are not yet established.

## Reproducibility

- Track code, configuration files, and experiment documentation.
- Record dataset sources and applicable licenses.
- Keep credentials, private images, model weights, and large datasets out of Git.
- Report actual experimental results without fabricating metrics.
