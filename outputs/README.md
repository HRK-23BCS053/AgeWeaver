## Auditability & Logging
Every generation trial appends full reproducible parameters to `experiment_log.csv` and `experiment_log.jsonl`:
- Denoising strength ($\sigma$)
- Guidance scale ($s$)
- Seed and inference step count
- ArcFace identity cosine similarity ($S_{id}$)
- Estimated target-age MAE ($E_{age}$)
- Cyclic round-trip similarity ($S_{cyc}$)
- Wall-clock CPU runtime
